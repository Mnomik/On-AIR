# Reporting security issues

On-AIR is a catalog of Windows applications. For a security concern affecting an application, contact Mnomik privately using the contact address in the StemSplit application footer. Include the project name, version, affected feature and a description of the issue. Please leave private files, credentials and unpublished vulnerability details out of public issues.

- [Harmonic Flow](https://github.com/Mnomik/Harmonic-Flow)
